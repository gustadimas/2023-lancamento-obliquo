# Lançamento Oblíquo

Isso é de abr/2023, da época da faculdade. Coloquei no GitHub em 2026 como registro e deixei como estava.

Simulação de lançamento oblíquo em 3D. A partir do ângulo, a bola calcula a velocidade inicial que precisa pra cair numa cesta na posição (3, 15), e a posição é atualizada a cada frame pelas equações do movimento, sem Rigidbody. Tudo no `ball.cs`.

## Como abrir

Abra a pasta do repositório pelo Unity Hub (Add project from disk). Usei o Unity 2021.3.15f1. A pasta Library não está no repositório; o Unity gera de novo na primeira vez que abre.

## Créditos

O modelo da moto e os materiais em `Assets/Nova pasta` vieram de um pacote de terceiros (`MOTO150CC.unitypackage`).
